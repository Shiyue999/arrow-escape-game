# 一箭又一箭（Arrow Escape）

一个使用 Python Tkinter 完成的点击式箭头解谜小游戏。玩家需要按照合适顺序点击箭头，使所有箭头安全飞出棋盘。

## 项目功能

- 开始界面、游戏界面、失败提示和通关提示；
- 棋盘显示上下左右四种方向箭头；
- 点击箭头后检测其前方整条路径；
- 前方无箭头时箭头飞出并消失；
- 线段式箭头沿自身折线路径逐点收缩，并从箭头尖端向棋盘外延伸的过程动画；
- 前方有箭头时保留原箭头、显示碰撞反馈并扣除一次失误机会；
- 每关 3 次失误机会，失败后可重新开始当前关卡；
- 3 个经过路径验证、可以正常通关的关卡；
- 折线箭头覆盖棋盘多个点，第 1 关的 8 条路径恰好覆盖 7×7 棋盘的 49 个点；
- 自动化测试覆盖路径检测、碰撞、失误耗尽、重置和关卡可解性。

## 运行环境

- Python 3.10 或更高版本；
- Tkinter（Windows、macOS 的官方 Python 通常自带）。

本项目只使用 Python 标准库，不需要安装第三方依赖。

## 运行方法

在项目根目录执行：

```powershell
python main.py
```

操作方法：点击棋盘上的箭头。箭头会沿自身方向离开棋盘；如果前方存在其他箭头，则会碰撞并消耗一次失误机会。点击“重新开始本关”可以恢复当前关卡的初始布局和失误次数。

## 运行测试

```powershell
python -m unittest discover -s tests -v
```

## 关卡设计

关卡数据采用“路径点序列、箭头方向”的方式保存。每条路径可以延伸和转弯，箭头尖端位于路径末端；点击路径上的任意点都会选中对应的整条线。规则引擎会检查箭头尖端前方是否存在其他路径，只有无遮挡时整条折线才会离开棋盘。三个关卡均已使用规则引擎验证存在完整通关顺序。

界面参考用户提供的游戏视频，采用深色背景、点阵棋盘、彩色折线箭头、生命和计时信息；成功点击时不会把整条折线作为刚体平移，而是从尾部开始按路径点逐段裁剪，同时让箭头尖端沿出口方向延伸，最后完全离开棋盘。
